# Images Required for DecentCalendar Vanilla

The following image files are needed in this `img/` directory for the app to display correctly.

## Required Images

| Filename | Description | Source |
|---|---|---|
| `IPFS_Logo.png` | IPFS logo — used as favicon and IPFS status icon | [IPFS Branding](https://ipfs.tech/media/) |
| `IPFS_Companion.gif` | IPFS waiting modal background animation | [IPFS Companion](https://github.com/ipfs/ipfs-companion) |
| `Web3Storage.png` | Web3Storage logo for the waiting modal | [Web3.Storage](https://web3.storage) |
| `MetaMaskFox.png` | MetaMask fox logo for the wallet connect button | [MetaMask Brand Kit](https://metamask.io/press-kit/) |
| `SecretPyramid.gif` | Background animation (cyberpunk pyramid) | Copy from `../decent-calendar-react-app/src/assets/SecretPyramid.gif` |
| `Ommm_Token_Logo.png` | Ommm token logo | Copy from `../decent-calendar-react-app/src/assets/Ommm_Token_Logo.png` |
| `DecentSmartHome_Logo.png` | DecentSmartHome logo | Copy from `../decent-calendar-react-app/src/assets/DecentSmartHome_Logo.png` |

## Quick Copy from React App Assets

Run the following commands from the `decent-calendar-vanilla/` directory:

```bash
cp ../decent-calendar-react-app/src/assets/SecretPyramid.gif img/SecretPyramid.gif
cp ../decent-calendar-react-app/src/assets/Ommm_Token_Logo.png img/Ommm_Token_Logo.png
cp ../decent-calendar-react-app/src/assets/DecentSmartHome_Logo.png img/DecentSmartHome_Logo.png
cp ../decent-calendar-react-app/src/assets/Metamask_Logo.png img/MetaMaskFox.png
```

Then download IPFS_Logo.png, IPFS_Companion.gif, and Web3Storage.png from their respective brand kits.
