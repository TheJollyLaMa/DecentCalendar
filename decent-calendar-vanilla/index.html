Local calendar backups

Public availability

Only explicitly public events are included. Meeting IDs, private events, booking state and other browser data are excluded. Review titles and descriptions for private information before publishing.

Set your own provider in the Head's Storage provider controls first. A CID is not automatic wallet discovery or proof of permanent retention.
